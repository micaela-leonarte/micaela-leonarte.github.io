# micaela-leonarte.github.io

Personal CV and portfolio site, served with GitHub Pages at
https://micaela-leonarte.github.io/

## Editing

- `index.html`: profile, experience, education, projects, and post list
- `css/style.css`: colors and layout (light and dark mode via CSS variables)
- `posts/<name>/index.html`: one page per post; copy `example-post/` to start a new one
- `assets/images/`: profile photo, GIFs and figures
- `assets/cv.pdf`: CV download (add your file here)

## Publishing

Pages is set to deploy from the `main` branch, root folder. Push to `main` and the site updates within a minute or two.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
